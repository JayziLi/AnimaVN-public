# 同名 BGM 随机播放 + 封面音乐

状态：
- 封面音乐：已实现（2026-09-27），见下面「封面音乐」一节
- 同名随机：设计已确认，暂缓实现（用户：「你先换曲子吧 随机的今天不做」）。星绘的曲子已经先换成单首：日常 = 主界面、俏皮 = 甜梦游乐园，温馨、心动照下表换好；意识重构、风华正当时等做了随机再加
日期：2026-09-27

## 目标

用户原话：「俏皮用 甜梦游乐园 或 风华正当时 我们加一个随机播放的功能 两首歌曲随机选一首播放」「日常 换为主界面 或 意识重构」「封面用主界面」。

1. 一个音乐名可以对应好几首曲子，放的时候随机挑一首
2. 标题画面（封面）有自己的音乐，不再沿用「上次停下的地方」那首

## 已定的决定

| 项 | 决定 | 理由 |
|---|---|---|
| 怎么表示「好几首」 | **同名就随机**：场景包里允许好几条 BGM 用同一个名字，AI 点这个名字时在这几条里挑。不加表、不改库 | 比「一条挂多个文件」少一张表、一次迁移和一个多文件上传界面；插件页里就是多加一行、起一样的名字 |
| 名字规则 | BGM 的名字 / 别名只能和**同名的条目**共用，和别的名字撞了照样 409。背景不变，仍然不能重名 | 同名的几条就是一组；别名挂在组里任意一条上都算整组的 |
| 什么时候挑 | 按「在哪儿点的」固定地挑：同一处标签重看、读档、往下翻都是同一首；不同的地方各自随机 | 如果每次重新计算都重新随机，往下点一句台词就可能中途换歌 |
| 已经在放同一组 | AI 再写一次同一个名字，或者换到默认曲是这个名字的场景，**接着放**，不重新挑 | 现在同一首不会重放；随机以后也要保持这个手感 |
| 背景的默认曲 | 默认曲指向组里的任意一条时，都按整组随机 | 游乐园、美食街、游戏厅的默认曲是「俏皮」，它们也要随机 |
| 封面音乐 | 场景包上可以指定一首（设置 → 显示 →「封面音乐」）；没指定，或者那首删了、禁用了，放 BGM 列表里**排在最前面、没禁用的那一条**。都是具体的一条，不随机。包里没有 BGM 就不放。点「继续」后淡出，换成游戏里的音乐 | 用户先选了「固定放排第一的」，后来要求「可以设定封面曲，在封面设定；没有设定则默认播放第一个」。指定到具体一条，所以以后「日常」成了随机组，封面也还是固定放主界面 |
| 给 AI 看的列表 | `{{bgms}}` 里同名的只列一次，说明取排在最前面那条的；`{{current_bgm}}` 照旧是名字 | AI 只需要知道有哪些气氛，不用知道每个气氛有几首 |

## 行为细节

- **挑哪首**：组 = 同名（不分大小写）且启用的 BGM，按插件页里的顺序。用一个字符串算哈希取模挑一首
  - AI 写的标签：依据是「哪条回复、哪个 swipe、这条回复里第几个标签」
  - 换场景带出的默认曲：用这个背景标签的依据
  - 开场的背景默认曲：用对话第一条消息的 id
- **禁用**：禁用的条目不进组。一组全禁用 = 这个名字不存在，和现在禁用单首一样
- **默认曲下拉**（插件页里背景的「默认音乐」）：同名的只列一项，写作「俏皮（随机 2 首）」，存组里排第一条的 id
- **插件页 BGM 列表**：同名的几条旁边显示「随机 · N 首」；BGM 区的说明加一句「名字一样的几首会随机放一首」
- **游戏里的控制台**：当前音乐除了名字，再标出是组里的第几首，比如「俏皮 2/2」
- **预加载**：只预加载挑中的那首。和现在一样，不因为多了几首就多下载

## 封面音乐（已实现，2026-09-27）

用户原话：「你实现一下封面曲的设定吧 可以设定封面曲 在封面设定 星辉曲子设为 主界面。没有设定则默认播放第一个」。存在哪一层问过用户，选了存在场景包。

- **数据**：`scene_packs.title_bgm_id`，可以为空，空 = 放排第一的。老库跑 `AnimaBackend/scripts/migrate_scene_pack_title_bgm_column.py`（可以重复跑；本机的库 2026-09-27 已经跑过，跑之前备份在 `data/animabackend.db.bak-20260927-title-bgm`）
- **接口**：`GET /api/scene-packs` 多返回 `title_bgm_id`；`PUT /api/scene-packs/{id}` 收 `title_bgm_id`（不传不改，传 null 回到默认），必须是同一个包里的一首 BGM，否则 400；删掉这首 BGM 时包上的设置清空（和背景的默认曲一样）
- **界面**：游戏菜单「设置 → 显示」，「封面样式」下面一行「封面音乐」（BETA）。下拉的第一项是「默认:排第一的(xx)」，后面是这张卡场景包里启用的 BGM；设的那首删了或禁用了，下拉显示回默认。从标题画面点「设置」进去是同一页
- **播放**：标题画面开着时放这首，点「继续」后淡出、换成场景的音乐（`bgm.ts` 本来就会淡出淡入）
- **代码**：
  - 后端 `models.py`、`schemas.py`、`api/scenes.py`
  - 前端 `lib/api.ts`（`ScenePack.title_bgm_id`）
  - `plugins/scene.ts`（`titleBgmOf`）
  - `plugins/useScenePlugin.ts`（换卡时顺手刷新包列表，`titleBgmId` / `setTitleBgm`）
  - `vn/VNScreen.tsx`（标题开着放封面音乐）
  - `vn/VNSettingsPage.tsx`、`vn/vn.css`（`vn-set-select`）
  - `DebugApp.tsx`
- **测试**：
  - 后端 pytest 加了封面音乐接口一条、迁移脚本两条，全部 260 个通过；`tsc -b`、oxlint 通过
  - 浏览器里实测（先备份了 `app_settings`，测完核对没变）：
    - 星绘的标题画面放主界面
    - 点「继续」换成对话停下时的「甜蜜」
    - 返回标题又换回主界面
    - 设置页下拉切到默认、再切回「日常」，库里都跟着变
    - 控制台没有报错
- **星绘**：「同居日常 · 星庇所」的封面音乐设成「日常」（主界面）

## 不做

- 一条 BGM 挂多个文件、单独的「随机组」对象
- 每次进场景都重新随机（同一处固定）
- 播完一首自动换同组的另一首（BGM 本来就是单曲循环）
