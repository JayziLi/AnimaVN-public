# 视觉小说 · 背景和 BGM(场景包)—— 设计

状态:**已实现**(第一版)
日期:2026-09-23

## 结构

- 后端 `app/api/scenes.py`:`/api/scene-packs`(包 + 素材 + 文件)、`/api/tavern/cards/{id}/scene-pack`(绑定);
  名字校验和图片格式识别和立绘共用(`sprites.clean_label` / `sniff_image_mime`),音频按文件头认格式
- `frontend/src/debug/plugins/common.ts` —— 三个插件共用:模板 → 正则、按名字找素材、插块(新插件块插在已有插件块后面)
- `plugins/scene.ts` —— 背景 / BGM 插件:默认模板、宏、状态规则(`initialScene` / `applySceneTag` / `sceneAtEnd`)
- `plugins/useScenePlugin.ts` —— 调试台里的场景包状态(配置、包列表、当前卡的绑定和素材)
- `vn/bgm.ts` —— Web Audio 播放器单例;`vn/script.ts` 一次摘三类标签
- 示例场景包素材在 `frontend/public/vn/bg`、`frontend/public/vn/bgm`,授权见 `CREDITS.txt`

## 背景

立绘插件已经跑通:AI 在正文里写句内标签,预设里一个插件块告诉它有哪些表情,
视觉小说界面按标签换图。背景和 BGM 沿用同一套机制,差别在于素材要能跨卡共用、
而且它们是「状态」而不是「表情」。

## 已确认的决策

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| 1 | 素材归属 | **场景包**:一组背景 + BGM。卡绑定一个场景包,多张卡可以绑同一个 | 用户原话「卡可以绑定背景和 bgm 的预设,就像卡绑定角色立绘一样」;阿米娅和琴柳共用「罗德岛」,曲子只存一份 |
| 2 | BGM 触发 | **场景默认 + AI 覆盖**:每个背景可以指定一首默认曲;换场景时音乐跟着换,同一场景里气氛明显转变时 AI 写 `<bgm:…>` 覆盖 | AI 负担小;关掉 BGM 块就退化成「只跟着背景走」 |
| 3 | 素材来源 | 仓库里放一套免费授权的示例场景包;明日方舟的剧情背景和原声只导入本地数据库 | 示例能随仓库发布;方舟素材版权归鹰角,不进仓库 |
| 4 | 标签 | `<bg:{场景}>`、`<bgm:{音乐}>`,格式各自可改;冒号写法放宽匹配,和立绘一样 | 一致 |
| 5 | 提示词块 | 两个独立的块 `anima_bg` / `anima_bgm`,各自可开关;插在已有插件块后面 | 插件可调;可以只要背景不要音乐 |
| 6 | 状态语义 | 只在变化时写,没写就沿用。块里用 `{{current_bg}}` / `{{current_bgm}}` 告诉 AI 现在在哪、放什么 | 避免每条都重写,也避免历史被截断后 AI 忘了场景 |
| 7 | BGM 命名 | 按气氛起名(日常 / 温馨 / 紧张 / 悲伤…),曲名写在说明里 | AI 不知道一首曲子听起来什么样 |
| 8 | 存储 | 和立绘一样存 SQLite BLOB(deferred);图 ≤ 8MB,音频 ≤ 16MB(服务器 nginx 上限 20m) | 部署备份只拷数据库 |

## 数据

- `scene_packs`:id、name(唯一)、description
- `scene_assets`:pack_id、kind(`bg` / `bgm`)、label、aliases、description、data(BLOB)、mime、size、
  sort(同类里排第一的是默认)、focus_x(背景的竖屏焦点,0–100)、bgm_id(背景的默认曲)
- `card_scene_packs`:card_id → pack_id。删卡时删绑定,复制卡时复制绑定,删包时删全部绑定

名字规则和立绘一样:同一个包里同一类素材的名字 / 别名不能撞,不能带 `<>[]{}【】「」` 和换行。

## 状态怎么算

对话从头到当前这句,把所有背景 / 音乐标签按出现顺序依次应用:

- 初始:背景 = 包里排第一的背景;音乐 = 它的默认曲(没有就静音)
- `<bg:X>`:背景换成 X;如果 X 和当前背景不同、并且 X 有默认曲,音乐换成默认曲
- `<bgm:Y>`:音乐换成 Y
- 同一位置(标签紧挨着)的背景标签先于音乐标签生效 —— `<bgm:紧张><bg:走廊>` 也是「走廊 + 紧张」
- 对不上名字的标签忽略,控制台标红

调试台组装提示词时用的 `{{current_bg}}` / `{{current_bgm}}` 就是整段历史末尾的状态。

## 播放

- Web Audio:`fetch` → `decodeAudioData` → `AudioBufferSourceNode(loop)` → 每首一个 GainNode → 总音量
  - iOS Safari 不许网页改 `<audio>` 的音量,淡入淡出只能靠 GainNode
  - 解锁一次 AudioContext 之后,换歌不需要再有用户手势(`<audio>` 每次 play 都要)
  - 无缝循环
- 进入视觉小说那一下点击、以及界面里的每次点击都会尝试解锁,第一次点击就能响
- 换歌交叉淡入淡出 1.5 秒;同一首不重播;切到后台暂停
- 音量、静音按设备记在 localStorage
- 背景:旧图淡出、新图淡入,中间透一点黑;`object-position` 用 focus_x,决定竖屏裁哪一块

## 界面

- 插件抽屉:立绘 | 背景 | BGM | 语音(即将推出)。背景和 BGM 两页顶上都是同一个场景包选择器(这张卡用哪个包 / 新建 / 重命名 / 删除 / 载入示例)
- 背景表:缩略图、名字、别名、说明、竖屏焦点、默认音乐
- BGM 表:试听、名字、别名、说明、文件信息
- 视觉小说顶栏:音量按钮(弹出滑条 + 静音)
- 控制台:三类标签分别列出匹配结果,原文里三类标签都高亮;显示当前场景 / 音乐以及来源(默认 / 场景默认曲 / AI 标签)
