# 视觉小说局内菜单 · 流程版

状态:流程版已实现(视觉交给后续的设计稿)

## 目标

视觉小说界面补齐 galgame 该有的一套:标题画面、局内全屏菜单(历史 / 存档 / 角色 / 预设 / 模型 / 设置 / 开发者)、
等待 AI 时的反馈、随时插话。能复用调试台的全部复用,样式只做到「不割裂」。

## 已定的决定

| 项 | 决定 |
|---|---|
| 菜单形态 | 一个全屏菜单壳,左列导航、右边换页(历史 / 存档 / 角色 / 插件 / 预设 / 模型 / 设置 / 开发者);Esc / 「菜单」开关。竖屏时导航变成顶部一排可横滑的标签 |
| 历史 | 就是调试台的对话区(ChatPanel),酒馆默认的一条一块排版,能编辑、切分支、分叉、折叠旧消息。不带输入框。「显示原文」开关:关 = 去掉 `<sprite:…>` 等标签、展开宏;开 = 库里存的原文 |
| 存档 | 一格 = 调试台「对话历史」里的一个对话。同一条消息「重来」出的几个版本不算存档,在历史里 ‹2/3› 切。每格显示缩略图(那个对话结尾时的背景 + 立绘)、名字、时间、角色最后一句。「在当前位置存档」= 从当前这条消息分叉出一个新对话,人留在原对话里 |
| 角色 | 只改文字:直接嵌调试台右栏的角色卡面板 |
| 插件 | 2026-09-25 加:调试台的插件抽屉(立绘 / 背景 / BGM / 语音)原样嵌进来,语音页多了试音台和参数。见 `2026-09-25-vn-plugin-page-voice-bench-design.md` |
| 预设 | 调试台左栏的预设面板原样嵌进来 |
| 模型 | 调试台的「API 设置」原样嵌进来:连接、类型、BASE URL(含端口)、密钥、模型名、刷新列表、流式、连通测试,和调试台同一份数据,改哪边都同步 |
| 设置 | 文字(文字速度 / 自动播放间隔 / 文本框透明度 / 对白字号)、声音(BGM 音量)、操作(回车键 / 快捷键说明)、显示(思考过程 / 模型标签 / 标题画面 / 界面样式-开发中) |
| 输入框 | 一直显示,可以随时插话 |
| 插话 | 截断:玩家读到最新回复的第 N 句时发言,这条回复只保留到第 N 句,完整版作为这条消息的另一个分支留在库里;AI 还在生成时插话 = 先停下再截断 |
| 等待反馈 | 名牌先亮 + 呼吸的羽毛。有思考链时显示「正在思考 N 秒」块,点开看思考内容;没有思考链时显示「正在组织语言…」 |
| 加载 | 切对话(读档 / 新故事)时黑场 + 右下角羽毛 NOW LOADING |
| 标题画面 | 先做出来试用:背景是当前卡的场景,ANIMA 标题 + 羽毛;继续 / 新的故事 / 读档 / 设置 / 回调试台。设置里可以关掉 |
| 快捷键 | 空格 / 回车下一句,按住 Ctrl 跳过,A 自动,Esc 菜单,滚轮向上看历史,右键隐藏界面 |

## 不在这一版

配色和视觉(粉色要换,等设计稿)、语音、界面样式切换、存档记住读到第几句。
