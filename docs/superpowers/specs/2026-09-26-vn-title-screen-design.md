# 视觉小说封面(Beta):海报 / 电影

旧封面是「虚化背景 + 左边一行 ANIMA + 菜单」,太素。这一版让所选角色的立绘、表情、场景包都上封面,
两种样式在设置里切换。整个封面功能标成 Beta。

demo 定稿过程:A(主视觉)被否;B(海报)、C(电影)保留。用户的意见:不要装饰用的数字和大字背景,
多用角色素材;海报右边的纸面要跟着背景变色;左边的角色头像圈好用。

## 决定

| # | 问题 | 决定 | 理由 |
|---|---|---|---|
| 1 | 几种样式 | 海报、电影两种,设置「显示 → 封面样式」切换,默认海报 | 用户两种都要 |
| 2 | Beta 标记 | 设置里「标题画面」「封面样式」两行带 BETA 角标;封面左上 ANIMA 旁也带一个小 BETA | 用户要求标记 |
| 3 | 立绘怎么摆 | 和游戏里一样按脸对齐(`face_scan`),各样式只换参数。原图只画到腰的放大到盖住底边;低清图最多放大到原图 1.5 倍,再不够就整体往下挪 | 不同来源的立绘构图稳定,不露切边、不糊 |
| 4 | 主题色 | 从这张卡排第一的立绘取色(去掉肤色、近黑近白),统一亮度后当点缀色;取不到用原来的粉色 | 即插即用,玩家不用配 |
| 5 | 纸面颜色(海报) | 从当前背景取色:亮的场景 → 浅色纸染上场景色调;暗的场景(平均亮度 < 0.3)→ 深色纸、字反白。纸面上再叠一层重度虚化的背景,只取颜色(`mix-blend-mode: color`) | 用户要求「按背景的颜色变」;叠层让纸面有深浅变化,不是一块纯色 |
| 6 | 取色在哪算 | 前端 canvas 算,按图片地址缓存。取色请求的是缩小版(立绘 `?w=160`、背景 `?w=96`),`crossOrigin="anonymous"` 加载;读不了像素就用默认配色 | 新场景包、新立绘自动生效。原图地址早被游戏里的普通 `<img>` 缓存过(没有 CORS 头、缓存一年),同一地址再以 CORS 方式请求会被浏览器拦下 —— 换个地址才读得到,顺带只下几 KB |
| 7 | 表情反应 | 鼠标移到菜单上换表情,点立绘害羞一下。按立绘名字挑,每种场合一串近义词,第一个对得上的用,都没有就用默认表情 | 用上更多立绘;新卡不用配置 |
| 8 | 角色头像圈 | 海报横屏:左边一竖排;竖屏:纸面底部一排;卡多了可以滚,两头渐隐。电影:底部菜单多一个「换角色」,点了字幕的位置换成一排头像。点头像 = 切到那个角色(接着她上次的对话),封面不关 | 用户点名保留;取代原来「新的故事 → 角色网格」那一页 |
| 9 | 头像图从哪来 | 后端新接口按脸裁一张小图(见下);失败时用卡面头像,再不行用名字首字 | 13 张完整立绘几 MB,手机上只为画 44px 的圆太重 |
| 10 | 「新的故事」 | 给当前角色开一段新对话;还没选角色时提示先点头像 | 挑角色交给头像圈 |
| 11 | 电影:片头 | 先停在「上次的地方」(当前场景)打出最后一句,然后在场景包的其他背景间轮流淡入(每镜 6.5 秒,最多 5 个地方),每镜换一个表情、左上打地点名,转完回到上次的地方 | 用户要求多用素材 |
| 12 | 电影:继续 | 回到上次的地方 → 黑边收起、立绘移到游戏里的位置(用游戏的 `spriteStyle`)→ 封面淡出露出底下的游戏 | 无缝进游戏 |
| 13 | 封面上显示的字 | 作品名 = 卡片第一个标签(没有就不显示);名字;「上次 · 3 小时前」(对话的 updated_at);最后一句 = 最新一条回复里角色说的最后一句(去掉引号) | 对话名是酒馆格式的时间戳,不适合上封面 |
| 14 | 装饰 | 不用装饰性数字(编号、序号)、不用大字当背景。海报纸面右上印一张同角色另一张表情的脸部特写(很淡,只留脸周围一圈) | 用户明确不要数字和大字背景 |
| 15 | 字体 | 系统字体:中文宋体栈(Noto Serif SC / 思源宋体 / 宋体-简 / 宋体),英文 Garamond 系。不引网络字体 | 国内连 Google Fonts 不稳;Win11 自带 Noto Serif SC,安卓 / iOS 有各自的宋体 |
| 16 | 加载黑场 | 封面开着的时候不盖「NOW LOADING」,换角色由封面自己的转场遮 | 在封面上点头像换人时不闪黑屏 |

## 后端

`GET /api/tavern/cards/{card_id}/sprites/face?size=96`

- 取这张卡排第一的、启用的、有图的立绘;脸框用它的 `face_scan`,没有就用同尺寸画布上其他立绘的脸框,
  再没有就取图的上方居中一块
- 以脸为中心裁正方形(脸高约占 0.6),超出原图的部分透明;缩到 size×size(32–256),WebP 带透明
- `ETag` = 立绘 id + 版本 + size;`Cache-Control: private, no-cache` —— 每次问一下,没变回 304
- 卡不存在 / 没有带图的立绘:404;服务器没装 OpenCV:503。前端两种都退回卡面头像
- 裁图写在 `app/sprite_faces.py`(`face_thumbnail`),和找脸放一起

立绘图片 `GET …/sprites/{id}/image` 和场景素材 `GET …/assets/{id}/file` 多一个可选的 `?w=`(16–1024):
缩到这个宽度的 WebP(等比、保留透明),原图不比这宽就发原图;音频忽略它。写在 `app/images.py`。
