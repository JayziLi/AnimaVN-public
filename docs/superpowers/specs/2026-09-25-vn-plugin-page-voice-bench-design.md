# 视觉小说菜单的插件页 · 语音试音台和参数

状态：已实现（2026-09-25）

## 目标

用户原话："现在 galgame 里面我没法修改插件（立绘 背景 语音 bgm）的内容和设置，帮我搬进来。特别是语音，我需要功能完整些，比如替换声线、生成句子测试、还有一些参数调整。"

## 已定的决定

| 项 | 决定 |
|---|---|
| 插件页 | 局内菜单加一页「插件」（在「角色」和「预设」之间），把调试台的插件抽屉原样嵌进来。两边是同一个组件（`DebugApp.tsx` 的 `renderPluginsDrawer`）、同一份数据，改哪边都同步。抽屉自己的标题栏在菜单里隐藏，关菜单走「返回游戏」 |
| 跳转 | 菜单「预设」里点插件块，跳到插件页并滚到那个插件的提示词模板（以前是退出视觉小说、打开调试台的抽屉）。「设置 → 声音」里加一个「换声音 · 试音 · 调参数」按钮，直接打开插件页的语音 |
| BGM 试听 | 在菜单里试听完（或者试听中离开插件页），场景原来的曲子接着放。`bgmPlayer.startPreview / stopPreview` 先记下试听前的状态，停的时候还原；按钮的「试听中」只看 `preview`，场景自己在放的曲子不算 |
| 换声线 | 不加新机制，就是改这张卡的主声音（`card_voices`）。试音台里试着顺耳，点「设为「卡名」的主声音」 |
| 试音台 | 语音页里新加的一组（`components/VoiceBench.tsx`）：选声音、选情绪、输入任意一句（有几句常用的中文 / 日语句子可以一键填；例句旁边切「中文 / 日文」，这次试听就按那个语言念，和「参数」里的语言是同一个，没保存不影响游戏。换声音时框里还是内置例句的话，自动换成这个声音念的语言那一版，日语声音不会去念中文例句；情绪表里的 ▶ 也一样）；「念这句」「换一种念法」（不用缓存）「每种情绪各念一遍」（依次播放）。每次的结果留在列表里（最多 20 条），可以重播、下载 wav，每条标着用的情绪、参数、种子、耗时、是否命中缓存 |
| 参数存在哪 | 每个声音一份（`voice_profiles.params`，JSON，只存调过的项）。不同角色的模型要的参数不一样，所以不放在语音服务上。采样步数、情绪强度没单独设时跟语音服务 |
| 能调什么 | GSV：语言、语速、采样步数、温度、top_p、top_k、重复惩罚、句间停顿、断句方式、并行推理。IndexTTS：语言、语速、情绪强度（小服务只收这些）。默认值取自台式机上的 `api_v2.py`（top_k 15、top_p 1、温度 1、重复惩罚 1.35、句间停顿 0.3 秒、断句 cut5、并行推理开） |
| 试和存分开 | 试音台里调的是草稿，随请求一起发（`/api/tts/speak` 的 `tuning`，整组替换声音存着的语速、语言、参数），不影响游戏；点「保存到「声音名」」才写进声音。草稿和存着的不一样时标「没保存」，可以撤销 |
| 固定种子 | 只在试音台里用、不保存：对比参数时两次填同一个数，差别就只来自参数。存进声音的话，游戏里「重新生成」会一直是差不多同一种念法 |
| 缓存 | 没调过的参数不发给 api_v2，所以加这个功能之前的缓存照样命中。调过的参数进缓存键；试音台用和存着一样的参数时，和游戏共用缓存 |
| 保存之后 | 视觉小说里这个声音已经合成好、留在内存里的句子作废（`voicePlayer.forget`，由 `useVoicePlugin` 比较刷新前后每个声音的设置触发），接着要念的句子按新设置重新合成。改参考音频、权重、情绪行也一样 |

## 数据

- `voice_profiles.params`：JSON，默认 `{}`。老库跑 `AnimaBackend/scripts/migrate_voice_params_column.py`（可以重复跑；本机的库 2026-09-25 已经跑过，跑之前备份在 `data/animabackend.db.bak-20260925-voice-params`）
- 后端校验在 `schemas.VoiceParams`：拼错的参数名直接 422，不会悄悄当没调

## 不在这一版

- 浏览语音服务那台机器上的模型和参考音频文件（路径还是手填或导入 refs.json）。要做的话得在台式机上加一个列文件的接口
- 试音台的草稿不跨页面保留（离开插件页就没了，存过的除外）
