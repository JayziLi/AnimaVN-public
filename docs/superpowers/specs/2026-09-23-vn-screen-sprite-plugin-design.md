# 视觉小说界面 + 立绘插件 —— 设计

状态:**已实现**(第一版)
日期:2026-09-23

## 背景

后端和酒馆调试台已经完整,下一步是 galgame 式的呈现:立绘 + 对话框。
旧的 `index.html` 游戏要求模型输出 JSON,和酒馆预设(让模型写正文)冲突,
所以视觉小说界面重新做在调试台里,吃的是调试台的同一段对话。

## 已确认的决策

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| 1 | 界面放哪 | 调试台里的全屏模式,顶栏一级入口(手机也不折进 ⋯) | 共用卡 / 预设 / 对话 / 发送,历史天然接得上 |
| 2 | 立绘怎么触发 | **句内标签**,默认 `<sprite:{表情}>`,格式用户可改 | 不和预设抢输出格式;粒度到句 |
| 3 | 提示词怎么加 | **写进预设当一个新块**(`anima_sprite`),插在 chatHistory 之后 | 用户要在左栏看得见、能拖能改;原有块一个字不动 |
| 4 | 配置范围 | 标签格式 + 提示词模板**全局**(后端 app_settings);表情映射**按卡** | 手机电脑必须同一份格式,否则一边解析不了 |
| 5 | 竖屏布局 | 全屏自适应,横竖屏一套布局 | 用户横着竖着都玩 |
| 6 | 图存哪 | SQLite BLOB(`card_sprites.image`,deferred) | 部署备份只拷数据库,文件目录会被漏 |
| 7 | 素材 | Ren'Py 示例游戏 The Question 的 Sylvie + 校园背景(MIT) | 授权清楚;见 `frontend/public/vn/CREDITS.txt` |

## 结构

- `frontend/src/debug/plugins/sprite.ts` —— 插件本体:配置、模板 → 正则、`{{sprites}}` / `{{sprite_tag}}` 宏、往预设插块
- `frontend/src/debug/vn/script.ts` —— 回复 → 一句一句:摘标签记位置、按段落和引号切台词/旁白、`名字：「」` 认说话人
- `frontend/src/debug/vn/VNScreen.tsx` + `vn.css` —— 界面:打字机、立绘交叉淡入、历史(可跳回)、控制台(原文 + 每个标签的匹配结果)
- `frontend/src/debug/components/PluginsDrawer.tsx` —— 插件抽屉:块状态、标签格式、提示词模板、表情映射表
- 后端 `app/api/sprites.py`(`/api/tavern/cards/{id}/sprites`)、`app/api/app_settings.py`(`/api/settings/{key}`)

## 几条规则

- 标签从「结束位置在它之后」的第一句开始生效;写在回复最末尾的延续到下一条回复
- AI 写的名字对不上映射(名字和别名都比,不分大小写)时不切图,控制台标红
- 插块时跳过紧跟在历史后面的 `</xxx>` 收尾块 —— 很多中文预设用 `<history>` 包历史
- 一张图都没配时显示半透明占位长方形,写角色名 + AI 最近要的表情

## 没做 / 之后再聊
