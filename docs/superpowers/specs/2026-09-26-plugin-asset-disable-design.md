# 插件素材的禁用开关（立绘 / 背景 / BGM）

状态：已实现（2026-09-26）

## 目标

用户原话："立绘/背景/bgm 每个小的下面添加一个禁用按钮，这样我不想用这个素材也不必删除了。"

## 已定的决定

| 项 | 决定 |
|---|---|
| 粒度 | 每一张立绘、每一张背景、每一首 BGM 各一个「禁用 / 启用」按钮，在插件页（调试台抽屉和游戏菜单是同一个组件）每行的按钮区 |
| 禁用 = 什么 | 游戏里当它不存在，和删掉的效果一样：不进 `{{sprites}}` / `{{backgrounds}}` / `{{bgms}}`（AI 看不到它）、标签对不上它（立绘交给情绪模型挑别的，背景 / BGM 保持不变）、不显示、不预加载，存档缩略图也不用它。语音的情绪候选跟着立绘走，也不含禁用的 |
| 留着什么 | 行、图 / 音频文件、名字、别名、说明、排序、背景的默认曲都不动。名字照样占着，免得重新启用时和别的行撞名 |
| 默认项 | 「排第一的是默认」改成「排在最前面、没禁用的那个」。禁用的行不能「设为默认」 |
| 默认曲被禁用 | 背景的默认曲还指着它（重新启用就接着用），但游戏里不放：换到这个场景时不换曲，开场的场景没有音乐。下拉里标「已禁用，游戏里不放」 |
| 共用的场景包 | 禁用存在包里，绑这个包的卡都生效；包有两张以上的卡在用时，页面上会提示 |
| 全都禁用 | 等于没配：立绘显示占位框、用内置基础表情；背景显示默认背景 |
| 在哪过滤 | 后端只存 `enabled`，列表照样全返回。前端 `DebugApp` 里一处 `enabledOnly(...)`，游戏、提示词宏、语音、存档拿过滤后的；插件抽屉拿完整列表 |

## 数据

- `card_sprites.enabled`、`scene_assets.enabled`：布尔，默认开。老库跑 `AnimaBackend/scripts/migrate_asset_enabled_columns.py`（可以重复跑；本机的库 2026-09-26 已经跑过，跑之前备份在 `data/animabackend.db.bak-20260926-asset-enabled`）
- 改的接口：`PUT /api/tavern/cards/{card_id}/sprites/{id}`、`PUT /api/scene-packs/{pack_id}/assets/{id}` 收 `enabled`；复制卡时连禁用状态一起复制
- 已知的小代价：图片 / 音频地址里的版本号取自 `updated_at`，切一次禁用会让浏览器重新下载一次这个文件（改名字、说明本来也是这样）
