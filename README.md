# AnimaVN

一个 galgame 风格的 AI 对话游戏。玩家用自由输入与 AI 角色对话,AI 的回复以传统 galgame 的方式呈现:立绘居中、底部对话框、逐句推进、玩家可随时打断。

> 技术栈尚未最终确定,详见下方「技术方案」章节的讨论状态。

## 一、整体体验

- galgame 风格的对话游戏,玩家自由输入,与 AI 角色对话。
- AI 回复以逐句台词的方式推进,玩家点击/按键进入下一句。
- 玩家可随时打断当前对话,输入新内容,AI 从最新输入继续。
- 前端视觉与交互遵循传统 galgame 设计语言:立绘居中、底部对话框、说话人名字、点击推进、历史回顾等。

## 二、核心功能

### 对话与台词呈现
- 将 AI 整段回复解析为逐句台词,一句一句显示。
- 每句台词显示说话人名字和内容。
- 点击/按键推进下一句;随时可打断,已显示内容进入历史记录。

### 立绘(角色表情)
- 每个角色有预制的表情立绘(差分)。
- AI 输出时同步指定当前立绘,画面切换到匹配表情。
- 立绘切换需自然过渡(淡入淡出等)。
- 不做实时绘图,仅使用预制素材。

### 背景 / 场景
- 少量预制静态背景/地图。
- AI 可在需要时指定切换背景。
- 不做实时生成。

### 配音(可延后实现)
- AI 角色台词可配音(TTS,本地或云端)。
- 配音匹配台词情绪。
- 下一句语音提前预加载,避免卡顿。

### 模型选择
- 提供"选择模型"窗口,玩家可自由选择驱动对话的模型。
- 切换模型不影响当前角色和存档。

### 角色系统
- 支持导入角色(类似 SillyTavern 的 PNG 角色卡)。
- 角色包含:人设、世界观设定、立绘素材、(可选)配音音色。
- 角色可复用,同一角色可开多局不同存档。
- 角色数据保存在后端。

### 存档系统(galgame 风格)
- 支持多个存档位手动存档 + 自动存档。
- 存档为完整状态快照:对话内容、当前立绘、背景、进行到哪一句等。
- 可读取任意存档并继续;存档间相互独立(非树状分支)。
- 存档位带缩略图/摘要,方便辨认。

### 历史回顾(Backlog)
- 可往回翻看已出现的历史台词。
- 若有配音,可重播历史语音。

### 记忆 / 长期对话
- 长对话不遗忘设定或跑偏人设。
- 世界观设定按需正确调用。
- 玩家与角色的对话历史被持续记住。

### 选择肢(混合交互)
- 大部分时间自由输入;合适的剧情节点由 AI 给出 2–3 个选项。
- 自由输入与选项并存。

### 音乐
- 类似背景图,根据 LLM 输出切换背景音乐。

## 三、本期不做

- 实时 AI 绘图(立绘和背景均为预制素材)
- 好感度 / route / flag 好感系统
- Auto / Skip / 文本速度调节
- 树状对话分支(只做独立存档)

## 四、开发优先级

1. 自由对话 + 逐句呈现 + 随时打断(纯文字)
2. 存档 / 读档 / 自动存档
3. 立绘 + 背景切换
4. 配音
5. 记忆 / 世界观调用
6. 角色导入 + 模型选择窗口 + 选择肢 + 历史回顾

## 五、技术方案

- 前端:React + TypeScript + Vite。
- 前端只有一个应用 `frontend/debug.html`:左边预设、右边角色卡、中间对话的调试台,顶栏「视觉小说」进游戏界面(立绘、背景、BGM、语音、存档、历史、设置)。早期那套独立的 galgame 前端(`index.html`)已在 2026-09-24 删掉,现在的 `index.html` 只负责跳到 debug.html。
- 后端(AnimaBackend):Python + FastAPI + SQLAlchemy,SQLite 存储(单机自用,后续可平滑迁移 Postgres)。仓库里的 `AnimaBackend/` 目录就是它,后续酒馆插件等外部工具也直连它。
- LLM 接入:后端有一层 provider 适配(`AnimaBackend/app/llm/`),目前支持 Anthropic、OpenAI 兼容接口(含 OpenRouter、本地 Ollama 等)、以及一个无需 API key 的 Mock provider 用于本地开发联调。连接和模型在「API 设置」(视觉小说里是菜单 →「模型」)里管理。
- 提示词:酒馆格式的角色卡 + Chat Completion 预设,在浏览器里组装后经后端转发。AI 回复是普通正文,立绘 / 背景 / BGM 靠插件往预设里加的提示词块让模型写 `<sprite:…>` 这类标签,视觉小说界面切句、摘标签后播放。
- 存档:每段对话(以及从某条消息分叉出来的分支)就是一个存档,存在 `debug_chats` 表里。

### 如何运行

后端(FastAPI):

```
cd AnimaBackend
python -m venv .venv
.venv/Scripts/activate   # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -e .
cp .env.example .env      # 按需填写 API key,默认用 mock provider 即可跑通
uvicorn app.main:app --reload --port 8000
```

前端(Vite + React):

```
cd frontend
npm install
npm run dev
```

默认前端跑在 `http://localhost:5173`(打开会跳到 `/debug.html`),后端跑在 `http://localhost:8000`。Windows 上也可以直接双击仓库根的 `start.bat`。
